# 대시보드 데이터 (코호트) — dashboard_data_final

`코호트분석 통합본.pdf`(본문 + 부록)와 같은 값을 담은 대시보드용 CSV입니다.
모든 파일은 `build_cohort_report.py` 한 번 실행으로 PDF와 함께 생성되며, 각 행의 `source` 열에 근거가 된 통합본 섹션을 적었습니다.

- 데이터: Duolingo Spaced Repetition Dataset (12개 열 완전 중복 81행 제거, UTC)
- 기준 주간: 2013-03-01 ~ 03-07, 대상 82,467명 / 후속 관측: 2013-03-08 ~ 03-11 (4일)
- 세그먼트: 세그먼트 기본 6개 규칙 (R·F·M)

## 정의 (대시보드에서 이름을 구분할 것)

- **이탈 위험**: 후속 4일(3/8~3/11) 학습 기록 없음 (`risk=1`). 영구 이탈이나 앱 미사용을 뜻하지 않음.
- **4일 내 복귀율**: 후속 4일 중 1일 이상 학습 = 1 − 이탈 위험률.
- **다음날 재학습률**(01, 04): 활동일 d(3/1~3/6) 중 d+1에도 학습한 비율, 사용자-활동일 단위. 06의 D1(첫 학습일 다음날, 사용자 단위)이나 퍼널의 '다음날 재학습'(3/1 시작자)과 다른 지표. 최근 단발형은 학습일이 1일이라 계산 대상이 아님(빈칸).
- **학습량**: session_seen 합. `words_seen`은 기준 주간 합, `first_vol`은 관측 주 첫 학습일 합.
- **new_estimated**: 3/1 이전 학습 흔적(timestamp − delta)이 없는 사용자 (퍼널 분석과 같은 방식). 가입일 아님.
- 비율 열은 모두 % 단위(0~100).

## 퍼널 데이터와 연결

`12_user_level.csv`의 `user_id`가 키입니다. 퍼널 분석의 사용자 테이블(`users`: user_id, d0, days, d0_items, d0_acc, lang, next_day_return)을 받으면 user_id로 붙여 세그먼트 × 언어쌍, 첫날 학습량 × 후속 재학습 같은 교차 분석에 쓸 수 있습니다. 퍼널의 전체 퍼널 대상(3/1~3/4 시작, 55,256명)과 그룹 비교 대상(3/1 시작, 21,738명)은 이 파일의 82,467명과 분모가 다르므로 패널마다 대상 인원을 표기합니다.
