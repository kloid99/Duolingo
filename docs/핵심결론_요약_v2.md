# 코호트 분석 핵심 결론

2026-10-13, 보완 2026-10-14. 공개 관측 기록 분석·검토 수정 완료. 실제 서비스 실행 조건 검증 대기.

- 기준 주간 활성 사용자 82,467명, 관측 기록 NSM 달성 9,834명. 추적은 네 완전 UTC 날짜(금·토·일·월)이며 날짜별 기록 비율은 주말에 낮았다.
- 습관 형성형 14,583명의 추적 학습 없음 6,975명, 1일 학습 4,046명, 2일 이상 학습 3,562명.
- 마지막 기록일이 같은 사용자끼리 비교해도 세그먼트 차이는 유지됐다(3/7 마지막 기록: 꾸준형 59.7%, 습관 형성형 28.8%, 최근 단발형 15.4%).
- 주후보 A1은 하루 이상 비활동 후 첫 후속 학습을 한 재개자다. 대상 4,809명 중 완전 관측 2,880명에서 1,312명(45.6%)이 다음 두 날짜 중 추가 학습했다.
- 같은 3/8 기준 습관 형성형 A1의 추가 학습은 42.0%로, 전날에도 학습한 A0 49.7%보다 7.7%p 낮았다(95% 구간 4.5~11.0%p). 꾸준형·최근 단발형에서도 같은 방향이었다.
- 세션 간격 변동성과 반복학습은 탐색적 연관성이 있다. 같은 단어 성과 개선과 반복학습의 뚜렷한 관계는 확인하지 못했고 직접 복습 간격 효과는 작고 가중 방식에 의존했다.
- 첫 실험은 재개 직후 다음 학습일 계획 카드 1회다. 주 지표는 D1·D2의 추가 학습 비율이고 모든 배정자를 분모에 포함한다.
- +3%p·80% 검정력 가정: 총 8,692명. 실제 신규 자격 유입량·개시일이 없어 실행 일정은 미정이다.
- 실제 배정·노출·개입 효과 검증은 미실행이다. 실험 시스템·최신 데이터 연결이 후속 실행 조건이다.
