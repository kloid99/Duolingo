# 지표 정의서

- 대상: `learning_traces.13m.csv`
- 관측 주간: 2013-03-01 \~ 2013-03-07 (UTC, 7일)
- 잔존 판정 기간: 2013-03-08 \~ 2013-03-11 (UTC, 4일)
- 2013-02-28, 2013-03-12는 수집이 하루 중간에 시작·종료되어 관측 주간에서 제외한다.

## 0. 공통 정의

| 용어 | 정의 |
|---|---|
| 활동일 | 사용자가 1행 이상 기록한 UTC 날짜 |
| 세션 | 같은 `user_id`와 같은 `timestamp`를 가진 행의 묶음 (레슨 1회) |
| 학습 문항 수 | `session_seen`의 합 |
| 정답 수 | `session_correct`의 합 |
| 복습 기록 | `delta` ≥ 60초인 행 (같은 레슨 안에서의 재등장 제외) |
| 첫 활동일 | 관측 주간 안에서 사용자의 가장 이른 활동일 |
| 첫 세션 | 관측 주간 안에서 사용자의 가장 이른 세션 |
| 신규 추정 사용자 | 첫 활동일에 본 단어의 `history_seen` 최댓값 ≤ 5, `delta` 최댓값 ≤ 7일(604,800초), 2013-02-28 활동 없음, 첫 활동일이 3/2\~3/7인 사용자. 3/1 시작자는 2/28 부분 수집으로 기존 사용자가 섞여 제외 |
| 거의 새 단어 | `history_seen` ≤ 2인 행 (처음 보는 단어는 데이터에 없어 근사) |

## 1. 북극성 지표

| 지표명 | 산식 | 분모 기준 | 기간 |
|---|---|---|---|
| 주간 4일 이상 학습 사용자 수 | count(사용자 \| 활동일 수 ≥ 4) | 해당 없음 (사용자 수). 비율로 볼 때는 주간 활성 학습자 수 | 관측 주간 7일 |

## 2. 입력 지표

| 지표명 | 산식 | 분모 기준 | 기간 |
|---|---|---|---|
| 주간 활성 학습자 수 (WAU) | count(사용자 \| 활동일 수 ≥ 1) | 해당 없음 (사용자 수) | 관측 주간 7일 |
| 다음날 재학습률 | count(활동일 d 중 d+1에도 활동) ÷ count(활동일 d) | 사용자-활동일 조합 (d = 1\~6일차) | 관측 주간 7일 (기준일 3/1\~3/6, 확인일 3/2\~3/7) |
| 활동일당 세션 수 | 사용자별: 세션 수 ÷ 활동일 수<br>서비스 집계: 사용자별 값의 중앙값 | 사용자별: 해당 사용자의 활동일 수<br>서비스 집계: 주간 활성 학습자 | 관측 주간 7일 |
| 첫 학습일 학습량 | 사용자별: 첫 활동일의 학습 문항 수<br>서비스 집계: 사용자별 값의 중앙값 | 서비스 집계: 주간 활성 학습자 | 관측 주간 중 사용자별 첫 활동일 1일 |
| 첫날 다회 세션 비율 | count(첫 활동일 세션 수 ≥ 2인 사용자) ÷ count(신규 추정 사용자) | 신규 추정 사용자 | 사용자별 첫 활동일 1일 |
| 첫날 새 단어 비율 | 사용자별: 첫 활동일 거의 새 단어의 학습 문항 수 ÷ 첫 활동일 학습 문항 수<br>서비스 집계: 사용자별 값의 중앙값 | 사용자별: 첫 활동일 학습 문항 수<br>서비스 집계: 신규 추정 사용자 | 사용자별 첫 활동일 1일 |
| 첫날 단어당 반복 노출 | 사용자별: 첫 활동일 학습 문항 수 ÷ 첫 활동일 count(distinct `lexeme_id`)<br>서비스 집계: 사용자별 값의 중앙값 | 사용자별: 첫 활동일 고유 단어 수<br>서비스 집계: 신규 추정 사용자 | 사용자별 첫 활동일 1일 |

- 다음날 재학습률은 관측 주간 마지막 날(3/7)의 다음 날이 관측 주간 밖이라 3/7을 기준일에서 제외한다.

## 3. 군집화 피처

| 지표명 | 산식 | 분모 기준 | 기간 |
|---|---|---|---|
| 주간 학습 일수 | count(distinct 활동일) | 해당 없음 (사용자별 일수) | 관측 주간 7일 |
| 세션당 학습량 | 학습 문항 수 ÷ 세션 수 | 사용자별 세션 수 | 관측 주간 7일 |
| 복습 간격 | median(`delta`) ÷ 86,400 (일 단위) | 사용자별 복습 기록 | 관측 주간 7일 |
| 적시 복습률 | count(복습 기록 \| 1일 ≤ `delta` ≤ 7일) ÷ count(복습 기록) | 복습 기록 (`delta` ≥ 60초) | 관측 주간 7일 |
| 일일 목표 학습량 달성률 | count(활동일 \| 그날 학습 문항 수 ≥ 50) ÷ count(활동일) | 사용자-활동일 조합 | 관측 주간 7일 |

## 4. 가드레일 · 성과 지표

| 지표명 | 산식 | 분모 기준 | 기간 |
|---|---|---|---|
| 장기 복습 정답률 | 정답 수 ÷ 학습 문항 수 (`delta` ≥ 1일인 행만) | `delta` ≥ 86,400초인 행의 학습 문항 수 | 관측 주간 7일 |
| 적정 난이도 세션 비율 | count(세션 \| 0.70 ≤ 세션 정답률 ≤ 0.95) ÷ count(세션) | 학습 문항 수 5개 이상인 세션 | 관측 주간 7일 |
| 초기 학습 성과 (p_recall) | 첫 활동일의 정답 수 ÷ 첫 활동일의 학습 문항 수 | 첫 활동일의 학습 문항 수 | 관측 주간 중 사용자별 첫 활동일 1일 |
| 첫 세션 정답률 | 첫 세션의 정답 수 ÷ 첫 세션의 학습 문항 수 | 첫 세션의 학습 문항 수 | 관측 주간 중 사용자별 첫 세션 1회 |
| 학습 성과 개선율 | Σ(단어별 (마지막 활동일 정답률 − 첫 활동일 정답률) × 마지막 활동일 학습 문항 수) ÷ Σ(마지막 활동일 학습 문항 수) | 서로 다른 활동일에 2회 이상 학습한 단어. 해당 단어가 5개 이상인 사용자만 산출 | 관측 주간 7일 |

- 학습 성과 개선율은 같은 단어끼리 비교해 콘텐츠 난이도 차이를 통제한다. 2일 이상 학습한 사용자만 산출되므로, 전체 사용자 비교에는 장기 복습 정답률을 보조 지표로 함께 쓴다.
- 과거 정답률이 낮을수록 개선율이 높게 나오는 평균회귀·천장 효과가 있으므로, 집단 간 비교 시 과거 누적 정답률(`history_correct ÷ history_seen`, 문항 가중)을 공변량으로 통제한다(ANCOVA).

## 6. 제외 지표 (참고)

| 지표명 | 산식 | 분모 기준 | 기간 |
|---|---|---|---|
| 복습 불규칙성 | std(log10(`delta` ÷ 86,400)) | 사용자별 복습 기록 | 관측 주간 7일 |
| 규칙적 학습자 비율 | count(사용자 \| 활동일 ≥ 2 이고 활동일별 첫 세션 시각의 원형 표준편차 ≤ 2시간) ÷ count(주간 활성 학습자) | 주간 활성 학습자 | 관측 주간 7일 |

- 복습 불규칙성은 `delta`가 단어별로 계산되어 학습량이 많을수록 값이 커지므로, 규칙성이 아니라 학습량을 측정하게 되어 제외했다.
- 규칙적 학습자 비율은 학습 일수와 마지막 활동일을 통제하면 잔존율·정답률·개선율 차이가 없어 제외했다(기준 1\~3시간 모두 동일). 잔존과 연관된 규칙성은 학습 시각이 아니라 연속 학습이며, 이는 다음날 재학습률로 측정한다.
