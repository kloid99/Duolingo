# 수정 산출물 기반 대시보드 구성 계획

2026-10-13. [3팀 프로젝트](https://app.notion.com/p/3-bfa0b7d59eee83a89db901096978c2a0?source=copy_link)의 Tableau 방향을 기준으로 작성했다. 이번 작업은 변경 파일 검토와 구성 계획이며 대시보드 구현·게시 전이다.

## 1. 수정 내용과 계획에 미치는 영향

이전 프로젝트 메모리 이후 수정된 최종 보고서·핵심 요약·검토사항 수정 결과·검증 기록·manifest를 대조했다. Notion 메인·최신 세그먼트·대시보드 페이지도 재조회했으며 대시보드 페이지는 비어 있었다.

| 변경 또는 추가 확인 | 대시보드 반영 |
|---|---|
| R01~R06의 로컬 보완 완료, 실제 서비스 입력 미확인 | 분석 자료 준비와 실험 실행 상태를 별도 표시 |
| A1 45.6%의 적용 범위 명확화 | 1,312/2,880 및 초기 재개·비활동 1~2일 표본임을 표시 |
| 날짜·비활동 기간별 관측 표 추가 | 미완전 관측 1,929명(40.1%)과 미관측 셀을 공개 |
| 104명 제외·가중 상위1% 제외·언어 보정 | 주 결과와 같은 단위의 민감도 결과를 상세 근거에서 비교 |
| CV 제곱항 형태 진단 | 단일 OR을 모든 CV 구간의 일정한 효과·최적 규칙성으로 해석하지 않음 |
| 실험 D1~D7 보조 NSM 명세 | 향후 측정 계획에 포함, 현재 실제 결과는 미측정 |
| v3 실제 군집 산출물 확인 | 6개 운영 세그먼트 × K-means 3개 군집 비교 추가 |
| 의미 검증·읽기 전용 감사 보강 | 화면의 지표 ID·기간·분모·단위·원천도 검증 |

v3 K=3 실루엣은 0.3735, K=4/5/6은 0.3357/0.3188/0.3370이다. 비교 후보 중 K=3 선택 결과이며 전체의 최적 K를 확정하지 않는다. 별도 rfm_analysis의 전체 기간 115,222명·7개 규칙형 분류·K=4와 혼합하지 않는다.

## 2. 목적과 기본 흐름

‘누가 학습 기록을 이어가며, 어디에서 다음 학습 연결이 끊기고, 어떤 후속 실험을 제안하는가’를 보여준다. 프로젝트 팀과 발표 평가자가 읽는 분석 설명용 대시보드를 가정한다.

**전체 현황 → 행동 유형 → 학습 연결 → 가설 근거 → 실행 제안**

기준은 v3 사용자 82,467명과 최신 수정 보고서다. 기준 주간 2013-03-01~07 UTC, 추적 03-08~11 UTC를 첫 버전에서 고정한다. 메인에는 프로젝트명·기간·탭·정의/출처·필터 초기화를 두고 ‘공개 학습 기록 기준’임을 명시한다.

## 3. 화면 구성

### 1 — 전체 현황

질문: 기준 주간과 추적 기간에 얼마나 기록 활동을 이어갔는가?

- 상단 KPI 4개: 주간 활성 82,467명 / NSM 9,834명(11.9%) / 추적 4일 재학습 29,240명(35.5%) / 추적 중 2일 이상 13,466명(16.3%).
- 중앙: 6개 집단의 ‘추적 기록 없음 / 1일 기록 / 2일 이상 기록’ 100% 누적 가로막대.
- 하단: 습관 형성형과 다음 학습 연결의 핵심 해석, 코호트·A1 상세 이동.
- 툴팁에 인원·분모·기간 표시. 세그먼트 선택 후 분자/분모를 사용자 데이터에서 함께 계산.
- 기준 NSM 달성 비율의 분모는 주간 활성자이며 향후 실험 NSM의 모든 배정자 분모와 다름.

### 2 — 행동 유형

질문: 6개 운영 집단과 3개 행동 군집은 무엇이 다른가?

- 인원·비중 막대와 추적 1일 이상/2일 이상 기록 비율 비교.
- 기준 주간 활동일·노출량·정답률 프로필, 6×3 세그먼트–군집 히트맵.
- 군집 C1/C2/C3는 ID를 유지하며 기준 프로필 설명을 붙임. 가입·성장·영구 이탈을 이름으로 단정하지 않음.
- 히트맵은 각 세그먼트 행 내부 비중. 전체 사용자 비중과 구별.
- K 후보 비교·ARI는 근거 영역에 배치. 운영 대상 선택은 6개 세그먼트를 기본으로 유지.
- 기본 프로필 정답률은 SUM(words_correct)/SUM(words_seen), 표시명 ‘노출 가중 정답률’. 기존 cluster_profile.csv의 accuracy_mean은 사용자 평균이므로 자동 대체하지 않음.

### 3 — 학습 연결과 코호트

질문: 고정 집단의 날짜별 활동과 재개 뒤 기록 연결은 어떻게 다른가?

- 모드 ‘고정 기준집단 / 첫 후속 학습일 기준’. 전환 시 제목·분모 설명 변경.
- 고정 모드: 03-08~11 날짜별 비율과 누적 1일 이상/2일 이상 비율. 일별 %를 합쳐 누적 사용자 %로 만들지 않음.
- 재개 모드: 행은 첫 후속 학습 날짜, 열은 D0~D3, 값은 해당 날짜 집단의 일별 기록 비율. D0는 정의상 100%이며 가입일이 아님.
- 미관측 셀은 회색·‘미관측’, 관측 후 기록 없음은 0%. 첫 학습이 늦은 사람의 추적 부족을 실패로 채우지 않음.
- 습관 형성형에서 A1 상세로 이동하되 일반 첫 후속 학습자와 비활동 1일 이상 재개자의 조건을 구분.
- 2일/3일 비활동 비교는 참고 패널. 3/11 종료 상태를 과거 개입 대상에 재사용하지 않음.

### 4 — 가설 근거와 안정성

질문: 어떤 관계를 확인했고 표본·정의에 얼마나 의존하는가?

- 가설 카드: 세션 간격 변동성 / 전체 정답률 변화 / 같은 단어 개선 / 직접 단어 복습 간격.
- 각 카드에 지표·결과 변수·사용자 수·추정값·개별 95% 구간·검정군/보정 여부·해석 표시.
- 상세: 주 분석, 104명 제외, 언어 보정, 가중 상위1% 제외 중 실제 저장된 모형만 제공.
- OR 그래프 기준선 1, 정답률 차이 %p 그래프 기준선 0. 별도 패널과 단위로 표시. CV 1SD와 정답률 +10%p의 OR을 효과 크기 순위로 해석하지 않음.
- 표본 선택 패널: 습관 형성형 14,583명 중 CV 10,633명, 전체 정답률 4,653명, 같은 단어 8,354명. 포함/제외 반복률과 구성 차이 표시.
- CV 곡률은 해석 주석. 최적 CV·예상 유지율 계산기 등은 추가하지 않음.
- ‘뚜렷한 근거 부족’도 주요 결과로 표시. 세그먼트·언어 필터에 따라 저장 모형이 재적합되는 것처럼 표현하지 않음.

### 5 — A1 연결 지점과 실험 제안

질문: 누구에게 언제 무엇을 제안하며 실제 실행에는 무엇이 필요한가?

- KPI: A1 후보 4,809명 / 완전 관측 2,880명(59.9%) / 미완전 관측 1,929명(40.1%) / 완전 관측 중 추가 기록 1,312명(45.6%, 95% 구간 43.7~47.4%).
- 분기: 후보 → 관측 완전/미완전, 완전 관측 → 추가 기록 있음 1,312 / 없음 1,568. 관측 완전성 분기를 사용자의 전환 단계로 표현하지 않음.
- 날짜·직전 비활동 기간별 후보/관측 분모/결과 표. 3/8 42.0%, 3/9 48.5%, 3/10·11 미관측.
- 실행 제안 카드: 습관 형성형, 비활동 1일 이상 뒤 첫 재개, 다음 학습일 계획 카드 1회, 사용자 1:1 배정, D1·D2 추가 학습 주 지표.
- 보조 NSM: 모든 배정자 중 D1~D7 기록 4일 이상. 현재는 미측정.
- 실험 상태 ‘설계 완료·실제 미실행’. 실제 배정 0명, 실제 효과/군간 차이는 미측정, 개시일 미정.
- 표본 계획은 보조 패널: +3%p·80% 검정력 가정 8,692명. 신규 실제 기준률·유입량·사업 기준 확인 전 확정 실행 일정으로 표시하지 않음.
- A1 화면의 분류는 습관 형성형 고정. 재개 날짜·직전 비활동 기간만 필터로 제공. B 복귀 유도 후보는 별도 목적·분모의 부록.

## 4. 데이터 준비와 단위

원본 전체를 재분석하지 않고 검증된 CSV/JSON을 변환한다. 구현 단계에서 새 dashboard/data 폴더를 만들고 기존 분석 산출물을 보존한다.

| 제안 출력 | 단위/키 | 원천·용도 |
|---|---|---|
| users.csv | 사용자 1명, user_id | user_retention_cohort.csv; KPI·세그먼트·군집·프로필 |
| user_days.csv | user_id × UTC date | user_daily_retention.csv; 일별 기록·비활동 |
| segment_metrics.csv | segment × metric_id × 기간 | users 집계, segment_retention_summary.csv와 대조 |
| return_cohorts.csv | segment × first_return_date × day_offset | first_return_cohorts.csv를 긴 형식으로 변환, observable 보존 |
| a1_candidates.csv | candidate_id | primary_candidate_eligibility/outcomes.csv의 유일키 연결 |
| a1_coverage.csv | grouping × value | review의 a1_date_and_gap_coverage.csv |
| hypothesis_effects.csv | analysis_id × model_id × term | regularity/accuracy_change/word_performance 주 결과 + corrections의 robustness_models.csv |
| analysis_coverage.csv | analysis × included | review의 analysis_selection_profiles.csv |
| experiment_plan.csv | experiment_id × setting_id | experiment_config.json 및 표본/기간 시나리오 |
| metric_dictionary.csv | metric_id | 현행 정의·보고서 계약; 표시명·기간·분모/분자·단위·출처 |

관계·계산 규칙:

- 사용자–날짜는 1:N. 사용자 행을 날짜 4행에 복제한 뒤 사용자 수·노출·NSM을 SUM하지 않음. 사용자 KPI는 사용자 단위에서 계산.
- A1 자격/결과는 candidate_id 1:1로 별도 연결. 이후 결과를 자격 기준에 넣지 않음.
- 코호트 집계·가설 효과·실험 설정은 사용자 데이터와 한 평면으로 합치지 않음.
- 비율은 합계 분자/합계 분모로 계산. 행별 % 평균을 전체 비율로 쓰지 않음.
- 미관측 비율·분자는 null, 후보 인원은 실제 값으로 보존. 기존 파일의 오래된 이탈 라벨은 현행 표시명으로 매핑.
- v3 군집 ID와 별도 RFM 군집 ID에 분석 버전 범위를 부여.

이번 직접 점검: users 82,467행·유일 ID 82,467개; user_days 329,868행·유일 user_id/date 329,868개; A1 자격/결과 각 4,809행·유일 candidate_id 4,809개. 모두 기준집단 안에 있으며 중복 없음.

## 5. 필터와 화면 규칙

| 조작 | 적용 범위 | 제한/계산 |
|---|---|---|
| 6개 세그먼트 | 화면 1~3 | 분자·분모를 같은 집단으로 제한, 전체 초기화 |
| 3개 군집 | 화면 2 사용자·교차표 | 보조 비교; 사전 집계 코호트에 임의 적용하지 않음 |
| 날짜 강조 | 화면 3 고정 모드 | 추적 4일 KPI의 기간을 바꾸지 않는 강조 |
| 첫 후속 학습일 | 화면 3 재개 모드 | 해당 날짜 첫 학습 집단 분모 |
| A1 날짜/비활동 기간 | 화면 5 | 후보와 완전 관측 분모 동시 갱신 |
| 민감도 선택 | 화면 4 | 저장된 모형만, 새로운 회귀 없음 |
| 주 학습 언어 | 2차 확장 | 기본 주간 최다 노출 언어 자료는 82,467명 모두 유일 ID로 존재. 사용자 KPI 연결 가능, 코호트 재집계 필요, 가설에는 자동 적용하지 않음 |

전체 화면은 6개 집단 순서를 고정하고 기록 상태 색을 일관되게 쓴다. 미관측은 별도 회색·문구로 표시하며 색만으로 뜻을 전달하지 않는다. %는 기본 소수 1자리, 작은 %p 효과는 원 결과 정밀도를 유지한다. 주요 비율에 분자/분모를 제공한다.

발표용 가로 1440×900을 기본안으로 화면당 주요 차트 2~3개를 배치한다. 상세 모형·전체 검정표·수식은 근거 영역에 둔다. Tableau 사용 환경과 공유 방식을 구현 시작 때 확인하고 게시 링크는 실제 게시 뒤 기록한다.

## 6. 구현 순서와 완료 기준

| 단계 | 작업 | 완료 기준 |
|---|---|---|
| 1 | 최신 파일 목록·해시·지표 사전·지원 필터 확정 | 모든 차트의 기간·단위·분자/분모·원천 정의 |
| 2 | CSV/JSON을 대시보드용 테이블로 변환 | 유일키·전체/부분 합계·null 보존·원천 대조 |
| 3 | 화면 1~3 제작 | 집단 순서·필터 분모·기간·미관측 정합 |
| 4 | 화면 4~5 제작 | 주/민감도·OR/%p·관측/제안/미실행 구분 |
| 5 | 수치·상호작용·레이아웃 검수 | 기준값·필터/초기화·단위·기간·분모 검증 |
