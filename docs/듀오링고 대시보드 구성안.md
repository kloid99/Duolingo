# 듀오링고 대시보드 구성안

Oct 19, 2026 · @지훈

## 1. 기준 자료와 핵심 메시지

이 구성안의 기준 문서는 노션 [BDAI 마케팅 자료](https://app.notion.com/p/5040b7d59eee827bbc08818b128d9567)다. 3주차 지표 체계·세그먼트, 4주차 퍼널·코호트가 팀 합의 버전이므로, 대시보드의 모든 숫자와 이름은 이 페이지를 우선한다. 개인 로컬 분석(v3 회귀·A1 실험)은 부록으로만 쓴다.

대시보드 성격은 **AARRR 기반 그로스·라이프사이클 마케팅 대시보드**다. 노션 AARRR 매핑대로 측정 가능한 Activation·Retention을 본문으로 두고, Acquisition·Revenue·Referral은 "측정 불가"로 명시한다.

헤드라인은 노션 "4주차까지의 분석 종합" 3개를 그대로 쓴다.

1. **학습일 수와 첫 학습 다음날의 재학습이 NSM 도달·재학습을 가장 잘 가른다.** 퍼널 1→2일 전환 54.1%(최저), 학습일 1일 복귀율 21.8% → 7일 96.6%.
2. **첫날 학습량은 어느 날 시작했든 강한 예측 신호지만, 인과는 실험으로 확인해야 한다.** 3/1 시작자 4일 달성률 15.8% → 43.3%.
3. **정답률(수준·변화)은 재학습의 레버가 아니다.** 대신 복습 간격이 짧을수록 정답률이 높다(91.7% → 88.0%).

공통 기준: 기준 주간 2013-03-01\~07 UTC 82,467명, 후속 관측 03-08\~11 4일, RFM 기준일 3/8. 퍼널은 3/1\~3/4 시작 55,256명, 그룹 비교는 3/1 시작 21,738명.

## 2. 참고한 마케팅 대시보드 사례

5개 레퍼런스에서 각각 한 가지씩만 가져온다. 공통점은 "상단 KPI 스코어카드 + 아래 리텐션·퍼널 차트 + 세그먼트 비교" 구조다.

**듀오링고 레퍼런스가 가장 중요하다.** 듀오링고는 사용자를 신규·현재·재활성·휴면 위험 등 7개 상태로 나누고 상태 간 이동률을 관리한다. 그중 전날 활동한 현재 사용자가 다음 날 돌아오는 비율(CURR)이 DAU에 가장 큰 영향을 준다고 밝혔고, 2026년 2분기 실적에서도 경영진이 가장 주시하는 지표로 CURR을 꼽았다([출처](https://www.customerexperiencedive.com/news/duolingos-user-retention-hits-all-time-high-as-app-boosts-stickiness/827499/)). 우리의 "다음날 재학습률 35.8%"는 이와 비슷한 개념이므로, 개요 페이지에서 "CURR 유사 지표"로 연결하면 발표 설득력이 커진다. 단, 정의가 다르다는 각주는 반드시 붙인다.

## 3. 공통 레이아웃

모든 페이지는 Looker Studio 마케팅 리포트의 3단 구조를 쓴다: 맨 위 KPI 스코어카드 줄, 가운데 메인 차트(8열)와 보조 차트(4열), 맨 아래 다음 행동·한계. 왼쪽에는 5개 페이지 사이드바를 고정한다.

&#91;embedded content: Overview 페이지 와이어프레임 · 사이드바 + KPI 6개 + 차트 4개\]

스코어카드는 NSM + 노션 Input Metrics 3개 + 4일 복귀율이며, NSM 카드만 강조색이다. 경고색(주황)은 Activation 페이지의 1→2일 병목 54.1%에만 쓴다. 나머지 페이지도 같은 틀에 KPI·차트 내용만 바꿔 넣는다.

## 4. 페이지 구성

노션의 분석 순서(지표 체계 → 퍼널 → 코호트 → 세그먼트 → 액션)를 그대로 페이지로 옮긴다. 페이지 이름은 AARRR 단계와 맞춘다.

| 페이지 | AARRR | 메인 차트 | 보조 카드 | 노션 근거 |
| --- | --- | --- | --- | --- |
| 1. Overview · NSM | 전체 | KPI 스코어카드 6개(NSM + Input 3개 + 복귀율 + 이탈 위험) | NSM 기준 선정 근거(2\~6일 이상 충족 비율), 학습일 수별 4일 복귀율 | 지표 체계 2️⃣·3️⃣ |
| 2. Activation · 습관 퍼널 | Activation | 1→2→3→4일 퍼널(전환율·이탈 인원) | 첫날 학습량 × 시작일 4일 달성률 히트맵, 첫날 정답률 × 학습량 교차표, 언어쌍 | 퍼널 2️⃣·3️⃣ |
| 3. Retention · 코호트 | Retention | NSM 달성 여부별 날짜별 당일·누적 재학습선 | 관측 주 첫 학습일 코호트 히트맵, 마지막 학습 후 경과일별 곡선 | 코호트 통합본 ①·⑤·부록 C |
| 4. Segments · RFM | Retention | 세그먼트별 고객 비중 vs 학습량 비중 쌍막대 + 집중도 | 4일 복귀율 막대, 세그먼트 × K-means 군집 비중 히트맵 | 세그먼트 3️⃣·5️⃣ |
| 5. Action · 가설과 실행 | — | 세그먼트별 액션 우선순위 카드 6장 | 가설 3개 결과 카드, 성공 지표 정의와 측정 가능 여부 | 지표 체계 1️⃣, 세그먼트 4️⃣ |

### 페이지별 메모

- **Overview**: NSM 기준 선정 근거 표(2일 이상 42.9% / 3일 22.1% / 4일 11.9% / 5일 6.2% / 6일 2.9%)를 작은 막대로 넣는다. "왜 4일인가"는 발표에서 반드시 나오는 질문이다. 하단에 AARRR 5단계 띠를 두고 Acquisition·Revenue·Referral은 회색 "측정 불가"로 표시한다.
- **Activation**: 노션 차트 01(퍼널)·02(그룹별 달성률)·03(시작일별 달성률)을 재사용 가능한 형태로 다시 그린다. 정답률 교차표는 "정답률 차이는 학습량으로 설명됨"이라는 결론 문장과 함께 둔다.
- **Retention**: 히트맵의 미관측 칸은 회색. 경과일별 곡선은 "공백이 길어지기 전에 개입"의 근거라는 문장을 카드 상단에 단다.
- **Segments**: 마케팅 RFM 대시보드의 표준인 "고객 비중 vs 매출 비중" 자리를 **고객 비중 vs 학습량 비중**으로 쓴다(노션 요약표 각주와 동일). 꾸준형 10.8% → 38.5%, 집중도 3.56이 이 페이지의 대표 숫자다. 습관 형성형은 C2 37% / C3 63%로 나뉜다는 점을 히트맵에서 강조한다.
- **Action**: 노션 세그먼트 4️⃣ 표를 카드로 옮긴다. 카드 형식은 `우선순위 · 대상 규모 · 진단 · 액션안 · 성공 지표 · 측정 가능 여부`. 액션 효과는 이 데이터로 확인할 수 없다는 노션 한계 문구를 페이지 상단에 고정한다.

Overview 스코어카드는 노션에서 확정한 NSM과 Input Metrics(노란색 3개)로 채운다. 1→2일 전환율은 Activation 페이지의 대표 KPI로 옮긴다.

| --- | --- | --- | --- |
| 주간 지속 학습 사용자 수 (NSM) | 9,834명 | 활성 대비 11.9% | 7일 중 4일 이상, 3/1\~7 |

### 지표 정의 (노션 형식)

| 지표명 | 계산식 | 집계 기준 (단위 / 분모 / 기간) | 값 |
| --- | --- | --- | --- |
| 주간 지속 학습 사용자 수 (NSM) | count(사용자 \| 활동일 수 ≥ 4) | 사용자 / 비율은 주간 활성 학습자 / 3/1\~7 | 9,834명 (11.9%) |
| 주간 활성 학습자 수 | count(사용자 \| 활동일 수 ≥ 1) | 사용자 / 해당 없음 / 3/1\~7 | 82,467명 |

| 학습량 (M) | 사용자별 session\_seen 합 (학습 문항 수) | 사용자 / 주간 활성 학습자 / 3/1\~7 | 합계 14,074,967문항, 중앙값 75 |
| 4일 복귀율 | count(후속 학습일 ≥ 1) ÷ 분모 | 사용자 / 주간 활성 학습자 / 3/8\~11 | 35.5% (29,240명) |
| 반복학습률 | count(후속 학습일 ≥ 2) ÷ 분모 | 사용자 / 주간 활성 학습자 / 3/8\~11 | 16.3% (13,466명) |
| 이탈 위험 | count(후속 학습일 = 0) ÷ 분모. 영구 이탈 아님 | 사용자 / 주간 활성 학습자 / 3/8\~11 | 64.5% (53,227명) |
| 집중도 | 학습량 비중 ÷ 고객 비중 | 세그먼트 / — / 3/1\~7 | 꾸준형 3.56 \~ 멈춤-저활동형 0.24 |

**이름 통일**: 노션 세그먼트·액션 표는 "4일 복귀율", 코호트 통합본은 "1일 이상 재학습률"로 같은 지표를 부른다. 대시보드는 **4일 복귀율**로 통일하고, 코호트 통합본의 "2일 이상 재학습률"은 **반복학습률**로 부른다. 노션 성공 지표의 "다음 날 복귀율"은 다음날 재학습률과 정의가 같으므로 한 이름만 쓴다.

### Action 페이지 성공 지표: 측정 가능 여부

| 성공 지표 (노션 정의) | 연결 세그먼트 | 현재 기준값 |
| --- | --- | --- |
| 4일 내 복귀율 | 멈춤-꾸준형 | 있음: 45.7% |
| 다음 날 복귀율 | 최근 단발형 | 있음: 21.3% (3/7 학습자 8,444명 중 1,795명) |
| 4일 이상 학습 전환율 | 습관 형성형 | 없음: 개입 후 7일 관측 필요 |
| 개입 후 7일 중 학습일 수 | 멈춤-몰입형 | 없음: 후속 관측 4일뿐 |
| NSM 유지율 | 꾸준형 | 없음: 다음 주 관측 필요 |
| 알림 반응률 | 멈춤-저활동형 | 측정 불가: 알림 기록 없음 |

카드에는 기준값이 없는 지표를 "실험 시 측정" 칩으로 표시한다. 빈 숫자나 0으로 채우지 않는다.

### 가설 결과 카드 (노션 지표 체계 1️⃣)

| 가설 | 판정 | 카드 문구 |
| --- | --- | --- |
| 1. 복습 규칙성 → 리텐션 | 약하게 지지 | 학습일·최근성을 맞추면 4\~5일 학습자에서 규칙적일수록 2일 이상 재학습 6\~8%p 높음. 3일 학습자는 비일관 |
| 2. 정답률 변화 → 리텐션 | 지지 안 됨 | 상승·하락 그룹 차이 2%p 이내, 학습일·학습량을 맞춰도 동일 |
| 3. 복습 간격 → 학습 성과 | 지지(효과 작음) | 간격이 길수록 정답률 91.7% → 88.0%, 이전 노출 횟수를 맞춰도 유지 |

가설 1 카드에는 "최근성을 통제하지 않으면 결과가 반대로 나옴"을 반드시 각주로 단다. 심사자가 가장 먼저 의심할 부분이다.

## 6. 디자인 규격

SaaS 분석 툴(Amplitude·Mixpanel)의 공통 룩을 따른다: 밝은 회색 배경, 흰 카드, 얇은 테두리, 강조색 하나.

| 항목 | 규격 |
| --- | --- |
| 그리드 | 12열, 카드 간격 16px. 스코어카드 6개 = 2열씩, 메인 차트 = 8열, 보조 = 4열 |
| 배경·카드 | 페이지 #F7F7F8, 카드 흰색 + 1px 테두리 #E5E7EB, 모서리 8px, 그림자 없음 |
| 강조색 | 그린 계열 1색(예: #58A700 계열)을 "주목할 집단·지표"에만. 경고는 주황 1색(이탈·병목) |
| 세그먼트 색 | 6개 세그먼트 고정 색. 모든 페이지에서 같은 세그먼트는 같은 색 |
| 히트맵 | 단일 파란색 농도 스케일, 미관측 = 회색 빗금 |
| 타이포 | Pretendard. 스코어카드 숫자 28px Bold, 카드 제목 13px, 각주 11px 회색 |
| 스코어카드 | 제목 → 큰 숫자 → 비교값(작은 칩) → 기준·분모 한 줄. 레퍼런스 대시보드와 같은 4단 |
| 차트 선택 | 비교 = 가로 막대, 추이 = 선, 단계 = 퍼널 막대, 코호트 = 히트맵, 집단 위치 = 버블. 파이·도넛·3D 금지 |
| 카드 설명 | Mixpanel Boards처럼 모든 차트 카드 상단에 한 줄 인사이트 문장 |

듀오링고 로고·캐릭터(Duo)·공식 폰트는 쓰지 않는다. 브랜드를 연상시키는 정도의 그린 강조색까지만 쓴다.

## 7. 필터·데이터·표기 규칙

일반 마케팅 대시보드는 상단에 날짜·채널 전역 필터를 두지만, 우리는 **페이지별 필터만** 둔다. 퍼널(55,256명)과 코호트(82,467명)는 대상이 달라, 전역 필터 하나가 두 숫자를 어긋나게 만든다.

| 페이지 | 필터 바 | 금지 |
| --- | --- | --- |
| Overview | 없음 (고정 KPI) | — |
| Activation Funnel | 세분화 기준(첫날 학습량 / 정답률 / 언어쌍), 시작일 3/1\~3/4 | 세그먼트 필터 |
| Retention | 비교 축(NSM 달성 여부 / 세그먼트 / 학습 일수) | 날짜 범위 슬라이더 |
| Audience | 세그먼트 클릭 → 우측 상세 패널 | 세그먼트 재계산 |
| Campaign Plan | 카드 클릭 → 근거 지표 펼침 | — |

### 데이터

- 원본 재집계 없이 검증된 집계 CSV만 읽는다: KPI 요약, 학습 일수별, 퍼널 단계·세분화, 세그먼트 요약·날짜별, 경과일별, 첫 후속 학습일, 관측 주 첫 학습일 코호트, 가설 결과, A1 실험(약 10개 표).
- 집계 단위가 다른 표끼리 조인하지 않는다. 사용자 단위(82,467행)·사용자-날짜 단위(329,868행) 원천은 올리지 않는다.

### 표기

- 툴팁은 항상 `값 · 분자/분모 · 기간` (예: `24.4% · 3,562/14,583 · 3/8~11`).
- "다음날 재학습" 3종을 이름으로 구분: 다음날 재학습률(사용자-활동일), 첫 학습일 D1 재학습률, 퍼널 첫날 다음날 재학습.
- "이탈" 대신 "이탈 위험" 또는 "4일 미학습". 미관측은 0%가 아니다.
- 날짜는 UTC, 요일(3/9 토, 3/10 일) 병기. "첫 학습일"은 가입일이 아니다(퍼널 대상의 82%가 기존 사용자).

## 8. 리스크와 팀 결정 필요 사항

구현 전에 팀이 정해야 할 것이 4개 있다. 정하지 않고 만들면 발표 당일 숫자 불일치로 찔린다.

- [ ] **실험 대상 통일**: 코호트 통합본 PDF는 "습관 형성형 전체"(D1·D2 47.6%, 5,679명)를, 최종 보고서는 "A1 재개자"(45.6%, 2,880명)를 실험 대상으로 쓴다. 탭 5에는 하나만 올려야 한다. A1이 정의가 더 정밀하므로 A1을 권장한다.
- [ ] **퍼널과 코호트의 연결 방식**: 퍼널(첫 등장 3/1\~3/4, 주 내부 전환)과 코호트(기준 주간 → 후속 4일)는 대상과 기간이 다르다. 탭 2와 탭 3 사이에 "대상이 다른 두 분석이 같은 병목을 가리킨다"는 연결 문장을 명시하고, 숫자를 섞어 계산하지 않는다.
- [ ] **도구 확정**: 노션 WBS와 R&R은 Tableau, 최근 계획은 HTML 직접 제작이다. 노션 기록부터 맞춰야 역할·산출물 링크가 정리된다.
- [ ] **실험 지표 "다음 7일 NSM" 처리**: 코호트 PDF의 평가지표에 있지만 기준값을 계산할 수 없다. 탭 5에는 "보조 지표, 기준값 없음"으로 명시하거나 빼야 한다.

노션 자료와 대조하며 추가로 확인한 불일치:

- [ ] **1순위 액션 문구가 3가지다**: 노션 세그먼트 4️⃣ "주간 4일 목표·진행률 + 간격이 벌어지기 전 알림", 코호트 통합본 "학습 직후 다음 학습일 안내 + 주간 4일 목표", 최종 보고서 A1 "재개 직후 계획 카드 1회". Action 페이지에는 하나만 올린다.
- [ ] **가설 1이 두 버전이다**: 노션은 학습일 간격 CV(3\~6일 학습자 17,415명, 구간 비교), 로컬 v3는 세션 간격 CV 회귀(습관 형성형 10,633명, OR 0.705). 대상·방법이 달라 숫자를 섞으면 안 된다. 대시보드는 노션 버전을 쓴다.
- [ ] **노션 "대시보드 제작(5주차)" 섹션이 비어 있다**: 이 구성안 링크와 지표 정의 표를 옮겨 팀 기준 문서로 만든다.

### 구조적 한계 (한계 패널에 고정 표시)

- 관찰 데이터라 세그먼트·학습 일수가 재학습을 "만든다"고 말할 수 없다.
- 후속 4일, 그중 주말 2일 포함. D7·D30 리텐션과 장기 이탈은 판단 불가.
- 공개 단어 기록이 앱 전체 활동을 다 담는지 검증되지 않았다. "기록 없음"은 앱 미사용이 아니다.
- 결제·알림·가입 정보가 없어 매출·알림 효과·가입 퍼널은 다루지 않는다.
