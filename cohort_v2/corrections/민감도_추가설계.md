# 보완 민감도 분석 사전 기록

2026-10-13. 아래 계획을 추가 적합 이전에 저장한다. 기존 결과를 바꾸거나 유의한 임계값을 찾지 않는다.

- 기존 품질표의 원본 전체 기간 history_seen>1,000 사용자 104명을 정확히 재추출한다. 미래 정보가 포함된 품질 영향 점검이며 실험 자격·예측 변수로 사용하지 않는다. 기준 주간만의 해당 사용자 수도 별도로 보고한다.
- 기존 CV, 전체 정답률 변화, 같은 단어 개선과 노출 가중/동일 가중 복습 간격 모형을 그대로 적합한 결과를 기존 추정값과 대조한다. 그 뒤 104명 제외 적합을 수행한다. CV SD는 각 분석 표본에서 재산출되므로 SD와 단위를 함께 보고한다.
- 원래 복습 쌍 분석 표본에서 마지막 노출 가중 합계 상위 1%를 사용자 ID 오름차순 동률 처리로 고정하고, 그 사용자만 제외한 두 가중 모형을 적합한다. 이 순위는 기준 기간 정보로 계산한다.
- 중복 제거한 원본 기준 주간에서 사용자별 최다 노출 학습 언어를 산출하고, 포함/제외자의 언어·최초 관측 날짜 구성을 기술한다. CV 모형에 언어 고정 효과를 추가한다. 극소 언어(<50명)는 기타로 묶는다.
- CV log(1+CV)의 선형 가정은 중심화한 제곱항을 추가해 진단한다. 곡선 모형은 단일 OR로 요약하지 않는다. 형식 진단 p값은 인과성·외부 예측 검증이 아니다.
- 추가 민감도 모형의 p값은 하나의 보완 탐색 검정군으로 Holm 보정한다. 원래 검정군과 결과는 유지한다. 모형 형태 진단은 별도 진단으로 보고한다.
- 원본 해시·기존 캐시 해시를 확인하고, 기존 주 분석 재적합 대조·행렬 계수·수렴·점수 방정식을 검사한다. 결과는 별도 폴더에 저장한다.

다른 주간·가입/채널·진짜 세션 coverage·D1~D7 결과는 현재 데이터로 검증할 수 없으므로 외부 검증 대기로 남긴다.
