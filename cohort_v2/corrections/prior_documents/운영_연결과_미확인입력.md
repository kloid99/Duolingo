# 실제 운영 연결과 미확인 입력

2026-10-13. 역사적 분석·실험 제안 산출물은 완료했다. 현재 폴더에는 신규 서비스 실험을 배정·노출·관측하는 데이터나 연결 시스템이 없다.

| 실행 입력 | 현재 상태 | 실행 전에 필요한 연결·확인 |
|---|---|---|
| 최신 학습·대상 데이터 | 미제공 | 개시 직전 완전 7일 기준집단 생성, A1의 새 고유 자격 인원 확인 |
| 역사적 첫 이벤트 시각 | 완료 | 원본에서 A1 4,809명의 첫 후속·직전 timestamp 추출. 새 서비스에서는 실시간 이벤트 연결 필요 |
| 앱 카드 | 명세 완료, 구현 미실행 | 첫 이벤트 뒤 안전한 다음 화면에 1회 표시, 날짜 계획·닫기 저장 |
| 무작위 배정 저장소 | 계약 완료, 연결 미실행 | 실험+사용자 고유성, 1:1 블록, 원자적 저장과 재접속 시 기존 배정 반환 |
| 노출·품질·coverage 로그 | 계약·참조 검증 완료, 실제 로그 미제공 | 배정 ID 연결, UTC 발생·수집 시각, 날짜별 수집 완전성 확인 |
| 최소 의미 효과 | +3%p 작성 가정 | 서비스의 비용·가치와 허용 효과를 실행 전 확정 |
| 실제 신규 자격 인원/일 | 미제공 | 전체 방문자 대신 새 고유 A1의 일별 유입량·대상 모수 확보 |
| 개시일과 최종 일정 | 미정 | 위 연결·규모 확인 뒤 확정. 최소 14일·최대 28일 모집은 제안 |
| 실제 실험·후속 7일 유지 | 미실행·데이터 없음 | 배정·노출 및 충분한 후속 학습 관측 뒤 평가 |

`experiment_config.json`의 actual_launch_date와 actual_new_eligible_users_per_day는 null로 보존했다. 실제 배정·노출·실험 효과 결과를 역사적 행동이나 합성 검증으로 대체하지 않았다.

신규 데이터를 확보하면 cohort_snapshot → 자격 판단 → experiment_assignments → 앱 카드·learning_events → daily_log_coverage → ITT 결과 순서로 연결한다. 이번 제안의 로컬 참조 계산은 데이터 계약과 날짜 경계를 검증한 도구이며 서비스 배포 기능은 아니다.

현재 추가 접근 권한이나 대상 시스템 주소가 제공되지 않아 외부 시스템 변경을 수행할 수 없다. 실행 관련 미완료는 실제 데이터·시스템 부재에 따른 상태이며, 분석·제안서의 미작성 항목은 아니다.
