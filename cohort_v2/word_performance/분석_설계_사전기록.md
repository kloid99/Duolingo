# 같은 단어 성과 보완 분석: 실행 전 설계

추출 단계 품질 점검에서 최초 timestamp에 서로 다른 history 값이 겹치는 사례가 발견됐다. 결과 모형을 보기 전에 다음 처리를 추가했다: 같은 단어 개선율은 보존하되, 해당 사용자의 초기 과거 정답률을 미확정으로 두고 사용자별 보정 모형에서 제외한다. 직접 간격 모형은 초기 이력이 명확한 단어 쌍만 남겨 5개 조건을 다시 적용한다. 제외된 단어·사용자 규모를 보고한다. 나머지 가설·모형·검정군은 유지한다.

기록일 2026-10-13. 이번 결과를 계산하기 전에 정한 작업 설계다. 외부 사전등록이나 확증 연구를 의미하지 않는다. 기존 탐색 결과는 이미 알고 있다.

## 지표 재현

- 3/1~7 UTC만 설명변수에 사용하고 고정 v3 집단 82,467명을 유지한다. 결과는 3/8~11의 1일 이상 재학습/2일 이상 반복학습이다.
- 사용자 × 학습 언어 × lexeme_id × 날짜로 정답·노출 수를 합산한다. 서로 다른 날짜에 학습한 같은 단어의 첫·마지막 날짜 정답률 차이를 구한다.
- 사용자별 개선율은 단어별 차이에 해당 단어 마지막 날짜 노출 수를 가중한다. 대상 단어가 5개 이상일 때 주 분석에 포함한다. 10개 이상 조건은 미리 정한 민감도다.
- 같은 단어 초기 정답률은 개선율과 같은 마지막 날짜 가중으로 계산한다. 과거 누적 정답률은 각 단어의 기준 주간 첫 관측 시각 직전 history_correct/history_seen을 사용하며 첫 날짜 노출 수로 가중한다. 마지막 날짜의 누적 정답률을 초기 수준으로 사용하지 않는다.
- 같은 사용자·언어·단어·최초 시각에 이력이 여러 개이면 차이 여부를 점검하고, 일치가 확인되지 않으면 임의로 초기 이력을 선택하지 않는다.
- 원본 전체행 중복은 기존 방식으로 제거하고, 82,467명의 문항·정답·세션·활동일 수를 기존 v3과 대조한다. 결측 개선율은 0으로 채우지 않는다.

## 개선율과 이후 행동

주 분석은 습관 형성형의 5개 이상 대상 단어 사용자에서 개선율 +10%p당 반복학습 오즈비다. 로지스틱 회귀와 사용자별 HC1 표준오차를 사용한다.

보정: 같은 단어 초기 정답률(선형·제곱), 첫 관측 전 과거 누적 정답률, 활동일·최근성 범주, log(1+기준 주간 노출 수), log(1+세션 수), log(1+대상 단어 수), 첫 관측 날짜, 대상 단어의 첫–마지막 날짜 간격 가중평균. 사용자 수준이며 단어 행을 독립 사용자처럼 세지 않는다.

효과 행은 4개로 고정한다: 습관 형성형 반복학습(주), 전체 분석 가능자 반복학습, 습관 형성형 10단어 이상 반복학습, 습관 형성형 재학습. 기존 전체 정답률 변화와 같은 대상이 아니므로 OR/p 크기로 우열을 주장하지 않는다.

## 단어별 복습 간격과 성과의 직접 관계

- delta≥60초인 복습 기록만 사용한다. 원래 개선율에는 이 필터를 넣지 않는다. 따라서 직접 간격 분석의 대상 수는 별도로 표시한다.
- 사용자·언어·단어의 첫·마지막 복습 날짜에서 정답률, 노출 가중 평균 log2(delta/3600), 노출 가중 평균 log(1+history_seen)을 구한다. 서로 다른 날짜의 양쪽 기록이 있어야 한다.
- 같은 사용자·같은 단어를 짝지어 Δ정답률과 Δlog2간격을 회귀한다. 단어 쌍 5개 이상 사용자만 포함한다. Δlog2간격 1은 두 날짜의 노출 가중 기하평균 간격 비율이 2배라는 뜻이다.
- 보정: 첫 날짜 정답률(선형·제곱), 첫 날짜 평균 log2간격, 최초 관측 직전 과거 정답률, Δlog(1+history_seen), 첫–마지막 날짜 차이, 첫 복습 날짜 범주. 시간에 따라 변하지 않는 사용자·단어 특성은 짝 비교로 맞추지만 난도·노출 선택·시간 변화까지 제거한 인과 설계는 아니다.
- 주 추정은 마지막 복습 날짜 노출 수 가중 선형 회귀다. 표준오차는 사용자 단위 군집으로 계산해 여러 단어의 종속성을 반영한다. 모든 단어 쌍에 동일 가중을 둔 민감도를 함께 제시한다. 결과는 현재 정답률 차이 %p이며 미래 기억 유지 효과나 최적 복습 간격을 뜻하지 않는다.
- 기술 통계로 delta 구간별 정답률·노출·사용자 수를 제시하되 구간별 이용자·단어가 다르므로 인과 비교로 사용하지 않는다.

## 검정과 검증

개선율 모형 4개와 직접 간격 모형 2개의 주요 계수 총 6개를 한 검정군으로 Holm 보정한다. 각 95% 구간은 개별 구간이다. 유의한 조건을 찾기 위해 임계값을 추가하지 않는다.

원본 샘플의 같은 단어 첫·마지막 지표를 독립 재계산하고, 사용자별 합계·제외 인원·결과 분자를 대조한다. 로지스틱 모형은 독립 최적화, 직접 간격 모형은 사용자별 군집 점수와 독립 최소제곱 계산을 교차검증한다. 수렴·선형독립성·수치 오차를 확인한 후 결과를 전달한다.
