# 프로젝트 검토와 다음 작업

검토일: 2026-10-13. 현재 기준: OneDrive의 cohort_v2, 고정 6개 세그먼트. 노션은 검토 범위에서 제외했다.

## 판단

현재 프로젝트는 **단기 재학습 행동을 설명하는 탐색적 분석과 재현 가능한 산출물 정리까지 진행된 상태**다. 세그먼트·코호트·비활동·세션 간격·전체 정답률 변화의 계산 결과는 활용할 수 있다. 실제 이탈방지 효과나 다음 주 NSM 개선을 검증한 단계는 아니다.

앞선 작업 메모리의 ‘실험안 구체화만 남음’은 범위를 과도하게 좁힌 표현이었다. 기존 지표 정의서와 최근 분석의 측정 차이를 정리하고, 원래 정의의 같은 단어 성과 개선과 복습 간격–성과 관계가 어디까지 수행됐는지 보완해야 한다. 최근 분석을 폐기하거나 기존 코호트 전체를 다시 계산할 이유는 현재 검토에서 발견하지 못했다.

## 2. 이번 검토의 근거

- 작업 메모리, docs/03_지표_정의서.md, 사용자 제공 수정 코드와 현재 분석 코드, 단계별 결과 JSON·검증 기록·해석 문서를 대조했다.
- manifest_retention.json 및 통계·비활동·규칙성·정답률의 manifest 5개에 기록된 총 80개 파일 항목을 실제 SHA-256과 비교했다.
- 후속 분석의 44개 항목은 전부 일치했다. 기존 v3의 36개 항목 중 33개는 일치했고 run_segment_revision.py, segmentation/code_provenance.json, segmentation/segment_code_local.py는 변경됐다. 작업 메모리와 provenance에 기록된 OneDrive 경로 적응에 해당한다. 역사적 manifest는 덮어쓰지 않았다.
- 기존 독립 검증 기록을 확인했다. 규칙성은 150명 간격 재계산과 회귀 5개 BFGS 비교, 정답률은 200명 기간 집계·15,216명 경계 판정·6개 모형 7개 효과 BFGS 비교를 통과했다.
- 이번 검토에서 원본 전체 재집계, 회귀 재적합, 엑셀 재생성은 수행하지 않았다. 새 모델 결과나 실험 결과를 추가한 검토가 아니다.

## 3. 우선 정리할 정의와 해석

### 같은 단어 개선과 전체 정답률 변화는 다르다

기존 지표 정의서는 서로 다른 날짜에 학습한 **같은 단어**의 첫·마지막 날짜 정답률 차이를 계산하고, 해당 단어가 5개 이상인 사용자의 가중 개선율을 정의했다. 최근 분석은 3/1~3과 3/5~7의 **전체 학습 기록** 정답률 차이이며 양쪽 각각 20문항을 요구했다.

따라서 최근 비유의 결과를 ‘학습 성과 개선과 유지 사이에 관계가 없다’로 확대하면 안 된다. 최근 결과의 이름은 ‘초반·후반 전체 정답률 변화’로 유지하고, 원래 같은 단어 지표를 별도 행으로 관리한다. 학습 언어·단어 구성을 맞춰도 문제 난도나 사용자 동기 등 모든 교란이 사라지는 것은 아니다.

### 규칙성 지표를 한 이름으로 묶지 않는다

1. 같은 단어 복습 간격: delta를 사용할 수 있다. 사용자 접속 간격으로 해석하지 않는다.
2. 매일 비슷한 시각에 학습하는 정도: 일별 첫 학습 시각의 원형 변동 지표다.
3. 현재 산출한 세션 간격 변동성: 사용자 고유 timestamp 사이 간격의 CV다.

기존 문서에서 제외했다고 기록한 1·2번과 새로 분석한 3번은 동일하지 않다. ‘규칙성은 무관하다’와 ‘규칙성이 관련 있다’라는 문구를 그대로 병합하지 않는다. 현재 결과를 설명할 때는 ‘세션 간격 변동성’이라고 명시한다. 과거 제외 결론의 독립 실행 산출물은 이번 파일 탐색에서 확인하지 못했으므로 확정된 재현 근거로 확대하지 않는다.

### 분석 가능한 집단과 결과 지표를 구분한다

- 세션 간격 주 분석은 습관 형성형 10,633명, 30분 정의는 4,100명이다.
- 정답률 변화의 습관 형성형 분석은 4,653명이며 원래 집단의 31.9%다.
- 서로 다른 대상·척도·모형의 p값이나 OR만 비교해 ‘규칙성이 정답률보다 예측력이 좋다’고 결론 내리지 않는다. 예측력 비교는 같은 표본·결과·검증 세트에서 별도 수행해야 한다. 현재 목적에는 예측 모델 추가가 필수는 아니다.
- NSM은 7일 중 4일 이상 학습자 수다. 추적 4일 중 2일 이상 학습은 별도의 단기 행동 지표다. 후속 7일 NSM이나 D7/D30은 현재 기준 기간 뒤의 관측 길이로 검증할 수 없다.
- 관측 비율이 높다는 사실은 개입으로 늘릴 여지가 크다는 증거가 아니다. 습관 형성형은 실험 후보이며 효과가 가장 큰 집단으로 입증되지 않았다.

## 4. 권장 작업 순서

### 1순위: 가설·지표·결론을 한 표로 확정

산출물: ‘가설별 결론표’와 ‘v3 지표 정의 대조표’.

각 행에 질문, 정확한 산식, 기준·결과 기간, 분석 대상·제외 기준, 핵심 수치, 결론, 남은 한계를 기록한다. 가입일 대신 최초 관측일, 실제 세션 대신 추정 세션, 3일 비활동 대신 확정 이탈처럼 의미가 바뀌는 표현을 정리한다. 원래 정의와 달라진 분석은 대체했다고 숨기지 않고 별도 지표로 표시한다.

완료 기준: 모든 주요 결론이 한 개의 정의·분모·원천 산출물로 연결되고, ‘검증됨/탐색적 연관성/근거 부족/미수행’이 구분된다. 전체 재집계 없이 먼저 수행할 수 있다.

### 2순위: 원래 지표에 맞춘 학습 성과 보완 분석

산출물: 같은 단어 개선율 결과와 복습 간격–성과 관계의 범위가 명시된 짧은 분석 보고서.

- 기준 주간에서 사용자 × 학습 언어 × lexeme_id × 날짜로 정답·노출을 집계한다. 같은 단어를 서로 다른 날짜에 학습한 기록의 첫·마지막 정답률을 연결한다.
- 기존 정의의 ‘대상 단어 5개 이상’ 조건과 마지막 활동일 노출 수 가중을 우선 재현한다. 조건을 충족하는 인원과 제외된 인원을 먼저 보고한다. 같은 날짜 내 여러 기록을 중복 단어로 세지 않는다.
- 초기 수준, 활동량, 최근성, 관측 기회 등을 고려해 개선율과 후속 반복학습의 관계를 본다. 과거 정답률 이력은 어떤 시점의 값인지 명시하고, 설명하려는 변화보다 나중의 누적 이력을 초기 공변량으로 쓰지 않는다.
- 원래 질문인 복습 간격과 성과의 직접 관계는 단어 수준 delta와 해당 단어 성과를 연결해 별도 분석한다. 사용자별 세션 간격 CV와 혼용하지 않는다. 행 단위 모형을 사용하면 같은 사용자의 반복 기록을 독립 표본으로 세지 않는다.
- 주 가설·주 결과·보정 변수·검정군을 결과 확인 전에 정리한다. 학습량·간격 임계값을 계속 바꿔 유의한 결과를 찾는 방식은 사용하지 않는다.

완료 기준: 전체 정답률 변화 결과와 같은 단어 개선 결과를 구별해서 말할 수 있고, 직접 간격–성과 질문의 결과 또는 분석 불가능 사유가 남는다. 지표 정의서의 가중·보정 설계를 그대로 쓴다고 인과성이 보장되는 것은 아니다.

### 3순위: 행동 흐름과 실험 대상·시점을 연결

산출물: 행동 흐름 요약 1장과 후보 대상 정의서.

- 같은 고정 기준집단에서 ‘추적 중 재학습 없음 / 1일 학습 / 2일 이상 학습’을 요약한다. 사용자 행동 기록만 있으므로 노출→클릭→구매 같은 퍼널을 만들지 않는다.
- 복귀 뒤 다음 학습 연결을 볼 때는 복귀 D0와 관측 가능한 D1·D2를 맞춘다. 3/10·3/11 복귀자의 짧은 추적 기회를 0%로 바꾸지 않는다. 전체 분모 결과와 복귀자 조건부 결과를 별도로 둔다.
- 실험 후보는 우선 ‘습관 형성형의 학습 재개 직후 다음 학습 연결’로 좁힌다. ‘정확히 2일 비활동에서 복귀 유도’는 별도 실험 후보로 둔다. 두 목적을 하나의 실험·분모로 섞지 않는다.
- 대상은 개입 직전에 알 수 있는 정보로 정의한다. 3/11 종료 상태를 이용해 3/8 개입 대상을 정하는 식의 미래 정보 사용을 금지한다. 3/11의 2,902명 또는 8,549명을 복귀 직후 대상 인원으로 재사용하지 않는다.

완료 기준: 누구에게, 언제, 어떤 행동을 유도하는지 한 문장으로 설명할 수 있고 같은 정의로 대상 수를 산출할 수 있다.

### 4순위: 실행 가능한 실험 계획과 최종 보고서

산출물: 실험 명세 1건과 최종 보고서.

- 예시 주 가설: ‘습관 형성형의 학습 재개 시점에 다음 학습 계획을 돕는 안내가 이후 2개 날짜 내 추가 학습을 늘리는가’. 제안이며 확인된 효과는 아니다.
- 후보 시점에 사용자 단위로 무작위 배정하고, 기존 경험 대조군과 안내군을 비교한다. 일단 재학습한 사람만 사후에 분모로 남기지 않고 모든 배정 사용자를 포함한다.
- 단기 주 지표는 배정 뒤 정한 D1·D2의 추가 학습 비율 등 하나를 우선 확정한다. ‘2일’이 달력 날짜인지 48시간인지 일관되게 정한다. 실제 후속 7일 데이터를 확보하면 7일 중 4일 이상 학습을 중기 지표로 연결한다.
- 실험에 필요한 로그: 배정 시각·그룹, 안내 노출·발송, 학습 시각, 중복 노출, 해당 채널을 쓸 경우 수신 거부·불편 신호. 현재 데이터에 없는 값을 만들어 채우지 않는다.
- 표본 수·기간은 동일한 대상과 결과 정의의 기준률, 최소 의미 효과, 검정력, 신규 유입 가능 인원으로 산정한다. 기존 24.4% 전체 반복학습률을 복귀 직후 2일 내 추가 학습 실험의 기준률로 그대로 쓰지 않는다.
- 현재는 역사적 공개 데이터이므로 제출 가능한 산출물은 실험 제안서와 측정 명세다. 실제 시스템·신규 데이터 없이 효과 검증 완료라고 표기하지 않는다.

보고서 흐름은 ‘문제와 NSM → 6개 집단의 행동 차이 → 다음 학습이 끊기는 지점 → 가설 검토 결과 → 대상·시점·액션 → 평가 계획’으로 구성한다. 모든 검정표를 본문에 넣지 않고 주요 근거와 한계만 제시한다.

## 5. 우선순위를 낮출 작업

- 이미 검증된 코호트 전체를 다시 계산하거나 세그먼트 수·군집 알고리즘을 다시 바꾸는 작업.
- 날짜별 검정을 계속 늘리거나 현재 표본에서 유의한 조합을 찾는 추가 탐색.
- 가입·채널·알림·결제 정보가 없는 상황에서 획득 퍼널, ROI, 캠페인 반응률을 만드는 작업.
- 4일 추적만으로 장기 유지·NSM 개선을 입증하려는 작업.
