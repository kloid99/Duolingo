# 개입 후보 대상과 시점 정의

2026-10-13. 3번의 대상 정의와 역사적 행동 집계다. 기준 주간 2013-03-01~07 UTC의 세그먼트는 03-08 00:00 UTC에 고정했다. 실제 개입이나 효과 검증은 수행하지 않았다.

## 주후보 A1: 재개 후 다음 학습 연결

**기준 주간 습관 형성형이 직전 완전 UTC 날짜 하루 이상 학습 기록 없이 지내다가 첫 후속 학습 기록을 남기는 시점에, 다음 두 날짜 중 다시 학습하도록 돕는다.**

| 항목 | 정의 |
|---|---|
| 기준집단 | 기준 주간 활동 2~3일, 마지막 학습 3/6 또는 3/7인 고정 습관 형성형 14,583명 |
| 자격 | 3/8 이후 첫 학습 이벤트 발생. 직전까지 끝난 UTC 날짜의 연속 비활동 수≥1. 해당 후보 배정 이력 없음 |
| 직전 비활동 산식 | 자격 날짜−직전 마지막 학습 날짜−1. 3/6 마지막 학습 후 3/8 재개면 1일 |
| 시점 | 첫 학습 이벤트가 확인된 직후. 현재 집계는 이벤트 날짜까지 재구성했으며 실제 시각은 미추출 |
| 유도 행동 | 다음 학습 날짜를 정하고 이어서 학습하기. 안내 위치·문구·노출 조건은 4번 실험 명세에서 정함 |
| 역사적 결과 | 첫 학습 날짜 D0 다음 두 완전 UTC 날짜 D1·D2 중 1일 이상 학습 |
| 중복 | 같은 후보 유형에서 사용자당 처음 1회. 현재 관측 기간에서는 최초 후속 학습만 사용 |
| 후보 산출 | 3/8~11 총 4,809명. 3/8 1,307명, 3/9 1,573명, 3/10 971명, 3/11 958명 |
| 완전 관측 결과 | 3/8·9 대상 2,880명, 추가 학습 1,312명(45.6%, 개별 95% Wilson CI 43.7~47.4%) |
| 추적 불충분 | 3/10·11 대상 1,929명은 결과 미관측. 실패·0%로 채우지 않음 |

‘재개’의 뜻을 명확하게 하기 위해 직전 완전 날짜 1일 이상 비활동 조건을 이번에 추가했다. 이 조건은 최적 임계값을 검증한 결과가 아니다. 기존 첫 후속 학습 전체(A)는 전날 학습자 A0 2,799명도 포함하여 총 7,608명이다. 기존 2,704/5,679=47.6%는 A 전체의 완전 관측 비율이고 A1의 실험 기준률로 그대로 대체하지 않는다. 기준 주간 습관 형성형 전체의 4일 반복학습률 24.4%도 다른 지표다.

첫 후속 학습은 관측 기간의 첫 학습이며 신규 가입이나 실제 서비스 복귀 상태를 뜻하지 않는다. 같은 날짜 안의 여러 세션은 결과에서 학습일 1일로 센다. D1·D2는 달력 날짜이므로 이벤트 후 고정 48시간과 다르다. 실제 서비스의 현지 시간·추적 기간을 바꾸면 기준률을 다시 산출해야 한다.

## 별도 후보 B: 정확히 2일 비활동 이후 복귀 유도

**습관 형성형의 직전 두 완전 UTC 날짜에 학습 기록이 없음을 다음 날 00:00에 확인하고, 학습을 다시 시작하도록 돕는다.**

| 항목 | 정의 |
|---|---|
| 기준집단 | A1과 동일한 고정 습관 형성형 |
| 자격 | 자격 날짜−직전 마지막 학습 날짜−1=2. 사용자당 이 후보의 최초 1회 |
| 시점 | 두 비활동 날짜가 끝난 다음 UTC 00:00. 예: 3/6 마지막 학습, 3/7·8 기록 없음 → 3/9 00:00 자격 |
| 당일 정보 | 자격 당일의 학습 여부를 선정에 사용하지 않음. 당일 나중에 학습해도 최초 대상에서 삭제하지 않음 |
| 유도 행동 | 다시 학습 시작하기. 채널·발송 시각·문구는 별도 실험 설계 필요 |
| 역사적 결과 | 자격 당일 D0·다음 날짜 D1 중 1일 이상 학습 |
| 후보 산출 | 3/8 0명, 3/9 4,675명, 3/10 4,840명, 3/11 2,165명. 합계 11,680명 |
| 완전 관측 결과 | 3/9·10 대상 9,515명 중 2,147명(22.6%, 개별 95% Wilson CI 21.7~23.4%) |
| 추적 불충분 | 3/11 대상 2,165명의 다음 날짜 미관측 |

과거 날짜 종료의 비활동 스냅샷 인원을 다음 날 시작 후보로 연결했다. 3/11 종료의 2일/3일 대상 풀이나 1~2일 비활동 2,902명을 이번 과거 시점의 대상 수로 재사용하지 않았다. 후보 B에서 최초 자격을 지난 뒤 재차 2일 비활동이 생기면 다시 넣지 않아, 날짜별 전체 스냅샷 인원과 최초 자격 인원은 다를 수 있다.

A 전체와 B 중복은 4,705명이고, 주후보 A1과 B 중복은 3,298명이다. 첫 실험은 A1로 좁힌다. 향후 병행 실험을 한다면 공통 배정·노출 이력으로 교차 개입을 방지해야 한다. 이번 역사적 결과에는 배정·노출 정보가 없어 두 후보를 가상의 실험군처럼 비교하지 않는다.

## 정보 시점과 산출물

| 시점 | 대상 결정에 사용하는 정보 |
|---|---|
| 3/8 00:00까지 | 기준 주간 활동일·최근성·노출·세션·마지막 학습 날짜, 고정 세그먼트 |
| A 이벤트 직전/발생 시 | 앞선 학습 날짜, 이 기간의 앞선 활동일, 첫 후속 학습 이벤트 발생, 후보 배정 이력 |
| B 당일 00:00 | 전날까지의 마지막 학습 날짜·연속 비활동 수·앞선 후보 배정 이력 |
| 이후 측정 시점 | D1·D2 또는 D0·D1의 학습 기록. 대상 자격 목록에는 포함하지 않음 |

- `primary_candidate_eligibility.csv`: A1 4,809명, 자격 날짜·개입 전 정보만 포함. 같은 기간 고정 세그먼트의 역사적 후보다.
- `primary_candidate_outcomes.csv`: 같은 candidate_id에 연결되는 A1 이후 결과. 완전 관측 여부와 날짜별 학습을 보존했다.
- `candidate_eligibility.csv`: 참고 A0를 포함한 A 전체와 B의 19,288개 후보 사건. 사용자별 후보 유형마다 1회다.
- `candidate_outcomes.csv`: A 전체·B의 별도 결과. 서로 다른 결과 기간을 명시했다.
- `baseline_behavior_flow.csv`, `aligned_behavior_summary.csv`, `aligned_behavior_patterns.csv`, `first_learning_followup.csv`, `candidate_summary.csv`: 전 집단 흐름·관측 기간을 맞춘 비교·대상 규모의 집계다.
- `behavior_flow_results.json`: 원천 해시·기간·결과·검증 체크. 원천 4개는 기존 저장 해시와 일치했다.

이벤트의 실제 timestamp, 레슨 완료, 화면 노출·배정·수신 동의는 이번 일별 산출물에 없다. 원본 학습 기록에서 A 첫 이벤트 시각은 추출할 수 있으나 이번 대상 수 재구성에는 날짜 해상도를 사용했다. 레슨 종료나 알림 발송 시점을 현재 기록으로 확정하지 않는다. 실제 운영 대상은 최신 데이터와 정한 기준 주간으로 다시 만들고, 시스템의 이벤트·배정·노출 로그를 연결해야 한다.

82,467명 전체를 일별 원천의 날짜 집합으로 독립 재계산했고 19,288개 후보의 자격 날짜·직전 정보·결과를 대조했다. 4개 날짜별로 이후 날짜 활동을 제거해도 앞선 후보 목록이 동일했다. 미관측 결과는 빈칸으로 보존했다. 엑셀의 요약·관측 범위와 대상 표를 저장 파일에서 별도 대조한다.

완료한 범위는 행동 흐름과 대상·시점 정의다. 다음 4번에서는 A1의 배정 단위·안내 내용·주 지표·비교군·추적 기간·필요 로그·표본 수를 하나의 실험 명세로 정한다. 이번 후보 관측률은 역사적 기준 자료이며 실제 실험의 대조군 결과나 개입 효과는 아니다.
